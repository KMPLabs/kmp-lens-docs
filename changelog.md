# Changelog

## 0.1.0-rc.3

- Fixed report population coherence for minimal Apple projects where the final
  framework and header are observable without a primary machine projection.
- Strengthened pre-release qualification with sparse authority-state consumers.

## 0.1.0-rc.2 — candidate

- Improved compatibility with Gradle versions running on earlier supported JVMs.
- Removed the unnecessary bytecode-level runtime restriction.
- Compatibility documentation now focuses on qualified Gradle, Kotlin and Kotlin Gradle Plugin profiles.

## 0.1.0-rc.1

First public release candidate of KMP Lens.
