KMP Lens documentation preview

Get from your KMP build to a useful report.

KMP Lens is a passive Gradle plugin that observes the Apple framework produced by a Kotlin Multiplatform build.

Get started

Run the Apple build you already use, then open:

build/reports/kmp-lens/kmp-lens-report.html

The report is the place to explore the result. This documentation stays focused on installing KMP Lens, running it and reaching that report.

Release preview: 0.1.0-RC.1 is not published yet. The installation shown here is the candidate configuration for validation before release.
