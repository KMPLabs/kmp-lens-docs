<section class="hero">
  <h1>Get from your KMP build to a useful report.</h1>
  <p class="lede">KMP Lens is a passive Gradle plugin that observes the Apple framework produced by a Kotlin Multiplatform build.</p>
  <div class="actions">
    <a class="button" href="{{ '/getting-started/' | relative_url }}">Get started</a>
  </div>
</section>

Run the Apple build you already use, then open:

```text
build/reports/kmp-lens/kmp-lens-report.html
```

The report is the place to explore the result. This documentation stays focused
on installing KMP Lens, running it and reaching that report.

<div class="callout"><strong>Release preview:</strong> 0.1.0-RC.1 is not published yet. The installation shown here is the candidate configuration for validation before release.</div>
