# Generated symbols

Some Apple symbols are generated forms rather than independent application
declarations. Investigate labels a generator only when the current run matches a
qualified configuration and structure.

## Kotlin/Native

Kotlin/Native creates runtime support and structural Apple forms around Kotlin
declarations. The report can label these forms **Generated by Kotlin/Native**.
The Kotlin standard library is a distinct Origin; it is not interchangeable with
Kotlin/Native generated support.

## SKIE

In its qualified configuration, KMP Lens can identify supported SKIE-generated
Apple forms and label them **Generated by SKIE**. This does not assign an
Origin, dependency path or application source to the generated form.

## Origin and generation stay separate

**Origin** identifies the established owner of the exact declaration when that
concept applies. **Generated by** identifies the qualified mechanism that
created the exact Apple form. A generated form with no independent owner omits
Origin instead of displaying a misleading unknown value.
