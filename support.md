# Support

Before reporting a problem, check [Compatibility]({{ '/compatibility/' |
relative_url }}) and [Limitations]({{ '/limitations/' | relative_url }}).

When reporting a problem, include:

- KMP Lens version;
- Gradle, Kotlin, Kotlin/Native, and Java versions;
- Apple target and relevant normal build task;
- whether SOURCE observation is enabled;
- transformation compiler and version, if present;
- the smallest safe reproduction and relevant diagnostics.

Do not post proprietary source, private reports, credentials, signing material, or sensitive dependency information to a public channel.

The [public documentation repository](https://github.com/KMPLabs/kmp-lens-docs)
contains the user documentation and its issue tracker.
